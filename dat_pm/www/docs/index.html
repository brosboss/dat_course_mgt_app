What this system is for

Dat PM supports personnel administration including training: maintaining a catalogue of courses, recording who is nominated for each run, tracking attendance dates and status, and collecting course feedback. Your organisation may use some or all of these parts depending on your role.

This guide describes behaviour as implemented in the application. It is written for end users (training staff, administrators, and course participants), not for developers.

How training pieces fit together

These are the main ideas to keep in mind:

  • Personnel — Each member has a service number, name, current rank, and current unit. Nomination and eligibility use this information.
  • Course Name — The training catalogue entry for a course. It defines which ranks may attend and which earlier courses are mandatory prerequisites.
  • Course nomination — A formal list of personnel selected for a specific run of a course (with dates, organising body, and other run details). It can be saved as a draft, submitted when final, or cancelled.
  • Course attended — After a nomination is submitted, the system creates an attendance record for each nominated person, tied to that nomination. Dates and course status come from the nomination and later activity (such as feedback).
  • Feedback — A submitted evaluation linked to a course attendance record. It can affect how the system labels completion for reporting.
Important: Qualification for nomination is automatic: the system only treats someone as eligible if their rank, prerequisite history, and “already attended” status satisfy the rules for that course name. You cannot bypass those rules when saving a new nomination with ineligible names mixed in.

Course catalogue (reference)

Training administrators maintain Course Name records (the catalogue). Each course typically includes:

  • Qualified rank — One or more ranks allowed to attend this course.
  • Mandatory prerequisite course — Other courses that must already appear on a person’s submitted attendance history before they are treated as eligible for this course.
  • Optional metadata such as abbreviation, frequency, or course materials.

If no qualified ranks are set for a course, nobody will appear as “due” or qualified for that course until the catalogue is corrected.

Who can be nominated — qualification rules

For a given course name, a person is treated as qualified (eligible to appear on the “personnel due” lists and to be saved) only if all of the following are true:

  1. Their current rank is listed under that course’s Qualified rank in the catalogue.
  2. They have not already completed this same course in a submitted attendance record.
  3. Every mandatory prerequisite course listed for this course appears on their history as a submitted attendance for that prerequisite course.

If something fails (wrong rank, missing prerequisite, or duplicate attendance for that course), the system explains why when you use the Why? actions in the nomination experience.

When you edit an existing nomination, rows that were already saved may not be re-checked live for rank or attendance changes; new rows and changed service numbers are validated. If in doubt, coordinate with your training administrator to keep nominations accurate.

Course nomination — step by step

The main workflow is the desk page titled Course Nomination (internal route course-nomination-an). Open it from your training or course nomination workspace if your administrator has given you access.

Modes: New vs Edit

  • New nomination — Choose a course from the catalogue, define a course suffix, enter run details, pick people, then save.
  • Edit nomination — Search for an existing course nomination record (draft or submitted). The course and suffix come from that record; you can update people and (depending on status) run details.

Course suffix and document name

For a new nomination you must enter a Course suffix (for example a batch code, week number, or year-week label). The system combines it with the course name to form the nomination’s unique name so each run is distinct.

Course run details

Provide at least:

  • Organising body
  • Start date and End date (end date cannot be before start date)

Personnel due for this course

The left panel lists everyone the system considers qualified for the selected course. Use checkboxes to select people (already-added names appear highlighted). Use Add selected to nomination to move them to the nominated list.

Use Why? next to a name to see a short explanation of qualified vs not qualified.

Nominated personnel

The right panel is your working list. You can Remove someone before saving. Rows that are not qualified show in red; you must remove them before the page will save.

Saving

Save as Course Nomination (new) or Update nomination (edit) creates or updates the official record and then opens it in the standard desk form. Missing organising body, dates, or suffix (new only) will block saving.

Editing after the course end date

If you open a submitted nomination whose end date is in the past, the page may start in a read-only state. Use Edit anyway when shown to unlock changes. For submitted nominations, updates from this page typically adjust the nominated personnel list only; other header fields may need to be changed on the desk form if your process allows it.

Cancelled nominations

A cancelled nomination is read-only on this page; you cannot save updates to it here.

Course nomination record (desk form)

You can also work from the Course Nomination list and form in the desk, which holds the same information with additional optional fields (category, location, fee, materials, status, and so on).

  • A custom button may open the Course Nomination page described above.
  • The form shows a summary of how many personnel meet qualification rules and offers View qualified personnel to browse everyone qualified, with counts by unit/rank and indicators if someone is already listed on another nomination for the same course.
  • Why Qualified? helps explain the last edited row’s eligibility.

On first save, every nominated service number must be qualified; the system will reject the save if not.

Submitting a nomination is the action that registers the official attendance placeholders. Cancel reverses linked attendance records according to your organisation’s process.

After you submit a nomination

When a course nomination is submitted, the system creates or updates a Course attended record for each nominated service number, linked to that nomination. Course dates on those records follow the nomination’s start and end dates.

Course status on attendance

Attendance rows can show a Course status such as:

Status Meaning (typical)
Upcoming Before the course start date.
On Course Current date is between start and end (inclusive).
Completed with no Feedback After the end date, and no submitted feedback is linked yet.
Completed After the end date with submitted feedback.
Deferred / Absent / Overdue Other operational states your organisation may set or report on; some values may be maintained manually outside automatic date rules.

The system can refresh the automatically managed statuses on a schedule. Values outside that set (for example Deferred) may be preserved when updating.

Personnel course details (lookup page)

The Personnel Course Details desk page lets you pick a person and view two columns:

  • Courses attended — Their submitted history.
  • Courses eligible for — Courses they could be nominated for next; eligibility matches nomination (rank, prerequisites, and not already attended).

Use it for quick answers without building a nomination.

Course feedback (trainees)

The Course Feedback desk page lets participants submit feedback against a course attendance record. They enter a reference (often the full attendance document name) or their service number; if several courses match, the page asks which one to rate.

Some users have a restricted role that sends them only to this page after login; they cannot browse the rest of the desk. Those accounts must be linked correctly in the Create Operator setup and email matching rules your administrator configures.

Beyond training — personnel and reference data

Dat PM also supports wider personnel administration: master data (such as units, ranks, locations, grades), the main Personnel record with posting and promotion history, imports, postings (including Part 2 orders), strength returns, and specialised desk pages your organisation may enable. Training depends on accurate personnel ranks and complete attendance history, so keeping personnel and catalogue records up to date is part of a healthy nomination process.

Administrators typically use the ADMIN Dashboard workspace to open reference lists, personnel, course attendance, nominations, and feedback-related shortcuts.

Dashboards and workspaces

Depending on permissions you may see:

  • Training Dashboard, Course Nomination Page, and Personnel Course workspaces — entry points for training tools.
  • TRG Dashboard — A command-style overview with nomination-related activity (exact widgets depend on configuration).
  • ADMIN Dashboard — Reference masters, personnel, and training records (administrator-oriented).

Access and roles

What you see is controlled by your user roles. Examples include roles that can create, read, submit, cancel, or amend course nominations, maintain reference data, or submit feedback only. If you cannot open a page or save a record, ask your system administrator to assign the correct role or to fix catalogue data (ranks and prerequisites).
